# Security

## Reporting

Report vulnerabilities privately: [Report a vulnerability](https://github.com/enricoros/big-AGI/security/advisories/new).
If the form is unavailable, email [hello@big-agi.com](mailto:hello@big-agi.com) with "Security" in the subject.

Do not open public issues for unpatched vulnerabilities.

## Scope

In: this repository, its server routes, the published Docker image.
Out: upstream AI vendor APIs, and infrastructure you run yourself (reverse proxies, hosting platforms).

## Supported versions

Fixes land on `main` and ship in the next release and the `:development` Docker image. Only the latest release is supported.

## Process

A maintainer acknowledges within a week. Fix on `main`, then a GitHub Security Advisory crediting the reporter, unless they ask otherwise.
